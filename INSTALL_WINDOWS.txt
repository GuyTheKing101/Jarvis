JARVIX.WORLD FULL WEB PACKAGE

THIS BUILD ADDS
- Landing page for jarvix.world
- Login screen
- Full Jarvis dashboard
- Chat + multi-image analysis
- Modern English UI
- Cloudflare tunnel templates for api.jarvix.world
- Same backend serves both landing page and app

SETUP
1) Install Ollama.
2) Pull text model:
   ollama run llama3
3) Pull vision model:
   ollama run llava
4) In this folder:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
5) Copy .env.example to .env and edit values.
6) Start:
   run_server.bat
7) Open:
   http://localhost:8080

DEFAULT LOGIN
Username: admin
Password: change-me-now

DOMAIN PLAN
- jarvix.world -> landing page + app
- api.jarvix.world -> backend API via Cloudflare Tunnel

- Keep Ollama running locally
